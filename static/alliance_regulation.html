{{ORGANIZATION}}FUJIN-Pアライアンス運用規程

Operational Regulation for FUJIN-P Alliance at {{ORGANIZATION_EN}}

本規程は、{{ORGANIZATION}}を母体とするFUJIN-Pアライアンス（以下「本アライアンス」）の構成・運営・参加条件について定めるものです。本規程は公開文書とし、本アライアンスに関わるすべての者が閲覧できるものとします。なお、本システムは実験段階（FUJIN-P：Experimental Phase）にあり、商用サービスと同等のサービス水準を保証するものではありません。

第1章　総則

第1条（目的）

本規程は、{{ORGANIZATION}}におけるFUJIN-Pアライアンスの運用に関する基本事項を定め、サイト運営の自律性と相互連携の信頼性を両立させることを目的とします。

第2条（定義）

本規程において、各用語の定義は以下のとおりとします。

  1. FUJIN-P基盤とは、Webアプリケーションの構築・運用を可能にするソフトウェア基盤をいいます。FUJIN-Pの「P」はExperimental Phaseを意味します。
  2. FUJIN-Pアライアンスとは、FUJIN-P基盤を用いて構築された複数のFUJIN-Pサイトが、共通の規程のもとに連携するコミュニティの総体をいいます。アライアンスは組織や地域ごとに個別に設置されるものであり、本規程は{{ORGANIZATION}}を母体とするアライアンスに適用されます。
  3. FUJIN-Pサイトとは、FUJIN-P基盤上にFUJIN-Pソムリエが構築し管理する個別のWebアプリケーション群をいいます。
  4. FUJIN-Pソムリエとは、所定の研修を修了し、本アライアンスに登録されたFUJIN-Pサイトの管理責任者をいいます。DXソムリエの一形態として位置づけられます。
  5. ユーザーとは、FUJIN-Pサイトに登録し、そのサービスを利用する者をいいます。
  6. 運営主体とは、本アライアンスの設置・管理・規程改定等の権限を有する主体をいい、{{ORGANIZATION}}で別途定める運用規程により定めます。

第3条（アライアンスの構成）

本アライアンスは、以下の要素から構成されます。

┃
┣━ FUJIN-Pサイト A ━━ FUJIN-Pサイト B ━━ FUJIN-Pサイト C …
┃

┃

  1. 各FUJIN-Pサイトは、1名以上のFUJIN-Pソムリエによって自律的に運営されます。
  2. サイト間は、シングルサインオン（SSO）やアセット共有等の連携機能によって接続されることがあります。
  3. ユーザーは、個別のFUJIN-Pサイトに登録してサービスを利用します。

第2章　FUJIN-Pソムリエ

第4条（ソムリエの資格要件）

  1. FUJIN-Pソムリエになろうとする者は、運営主体が実施または認定する所定の研修を修了しなければなりません。
  2. 研修の内容、実施方法、および修了認定の基準は、{{ORGANIZATION}}で別途定める運用規程によります。
  3. 研修を修了した者は、本規程および関連文書（サイト利用規約、プライバシーポリシー等）の内容を理解したうえで、所定の同意書を提出することにより、FUJIN-Pソムリエとして登録されます。

第5条（ソムリエの責務）

  1. FUJIN-Pソムリエは、自身が管理するFUJIN-Pサイトについて、サービスの提供・運用・保守に関する一次的な管理責任を負います。
  2. ソムリエは、自身のサイトに登録されたユーザーの個人情報を、本アライアンスのプライバシーポリシーおよびサイト利用規約に従い適切に管理するものとします。
  3. ソムリエは、本規程その他のアライアンス規程を自身のサイト上に掲示し、ユーザーに周知する義務を負います。
  4. ソムリエは、自身のサイトで提供するサービスの内容について、以下の分類を参照し、適切なアクセス制御を行うものとします。
    FUJIN-Pサイトのサービス分類（参考）
    ・人的資源管理（まいぐる、あくまね等）
    ・FUJIN-Pアセット管理（アプシャ、テーシャ等）
    ・基本情報管理（コレポ、マイノート、テーブルマスター等）
    ・領域依存アプリ（けいこく年度、まいあし等）

第6条（ソムリエ情報の取り扱い）

  1. FUJIN-Pソムリエに関する情報は、以下の2種類に区分して取り扱われます。
    （A）公開情報：ソムリエが管理するFUJIN-Pサイトの名称・URL、および当該サイトが本アライアンスに属する旨。これらは各サイト上に掲示され、公開されます。

    （B）サイト間共有情報：ソムリエの連絡先メールアドレス（FUJIN-Pログインアカウント）。これは、サイト間のAPI連携パスワードと同等のセキュリティレベルで、アライアンス内の他のサイトのadminに対して共有されます。
  2. （B）のサイト間共有情報は、アライアンスソムリエとしての他サイトへのログイン許可、サイト間連携、および障害時の連絡を目的として共有されます。受領したadminは、APIパスワードと同様にこの情報を管理し、admin業務以外の目的に使用してはなりません。
  3. ソムリエの連絡先メールアドレスのサイト上への掲示は推奨されますが、義務とはしません。

第7条（メールアドレス共有のオプトアウト）

  1. FUJIN-Pソムリエは、自身のメールアドレスをアライアンス内の他のサイトに共有することについて、オプトアウト（不参加）を選択することができます。
  2. オプトアウトを選択した場合、当該ソムリエのメールアドレスは他のサイトのadminに送付されません。ただし、その代わりに、当該ソムリエは他のアライアンスサイトにアライアンスソムリエとしてログインする特権を受けることができません。
  3. オプトアウトの選択は、ソムリエ登録時または登録後いつでも運営主体に申し出ることにより変更できます。
⚠ リスクの告知
メールアドレスの共有に同意した場合、当該情報はアライアンス内の他サイトのadminに伝達されます。各adminはこの情報を適切に管理する義務を負いますが、万一、他のadminの過失等によりメールアドレスが不正に利用される可能性を完全に排除することはできません。ソムリエはこのリスクを理解したうえで共有の可否を判断してください。

第8条（守秘義務）

  1. FUJIN-Pソムリエ（admin）は、サイト間共有情報（他のソムリエのメールアドレス、API連携パスワード等）を、admin業務の範囲を超えて利用または第三者に開示してはなりません。
  2. ソムリエは、自身のサイトを通じて取得したユーザーの個人情報を、プライバシーポリシーに定める範囲を超えて利用または開示してはなりません。

第9条（ソムリエ資格の取り消し）

  1. 運営主体は、以下の事由に該当するソムリエに対し、警告、資格の一時停止、または資格の取り消しの措置をとることができます。
    1. 本規程またはアライアンスの関連規程に違反した場合
    2. 守秘義務に反してサイト間共有情報またはユーザーの個人情報を漏洩した場合
    3. ソムリエとしての管理責任を著しく怠った場合
    4. その他、運営主体がアライアンスの信頼性を損なうと判断した場合
  2. 取り消し措置の具体的な手続きは、{{ORGANIZATION}}で別途定める運用規程によります。
  3. 資格を取り消されたソムリエが管理していたサイトおよびユーザーデータの取り扱いについては、運営主体が適切な措置を講じます。

第10条（ソムリエ資格の自主返上）

  1. ソムリエは、いつでも運営主体に通知することにより、ソムリエ資格を自主的に返上することができます。
  2. 返上後のサイト運営およびデータの引継ぎについては、運営主体と協議のうえ適切に対応するものとします。
  3. 返上に伴い、他サイトへのメールアドレスの共有は停止され、アライアンスソムリエとしてのログイン権限も失効します。

第3章　ユーザーおよびサイト運営

第11条（ユーザーの位置づけ）

  1. ユーザーは、個別のFUJIN-Pサイトに登録してサービスを利用する者であり、当該サイトのソムリエがサービス提供の一次的な責任者となります。
  2. ユーザーの権利義務は、別途定める「FUJIN-Pサイト利用規約」によります。

第12条（取り扱いデータのレベル定義）

本アライアンスにおける情報は、以下の4段階のレベルに分類して管理されます。各ソムリエは、自身のサイトにおいてこの分類に基づく適切なアクセス制御を行うものとします。

レベル1（パブリック共有）：社会に周知されている、またはアライアンス外に広く公開される情報。
レベル2（アライアンス間共有）：SSO、アプシャ、テーシャ等の連携のために、アライアンス内の複数サイト間で共有される情報。
レベル3（コミュニティ内限定）：特定のFUJIN-Pサイト内でのみ共有される情報。
レベル4（業務・役割限定）：業務上の関係者にのみ限定して開示される高機密情報。

第13条（シングルサインオンと属性共有）

  1. アライアンス内のサイト間連携のため、Google認証等を用いたシングルサインオン（SSO）が導入される場合があります。
  2. SSOを利用するユーザーの基本的な属性情報（氏名、メールアドレス、所属等）は、連携先サイトに共有されることがあります。この共有条件はサイト利用規約およびプライバシーポリシーにおいてユーザーに明示されるものとします。

第14条（各サイトにおける掲示義務）

各FUJIN-Pサイトには、以下の事項を掲示するものとします。

  1. 当該サイトが{{ORGANIZATION}}におけるFUJIN-Pアライアンスに属するFUJIN-Pソムリエによって運営されている旨の宣言（サイト名・URLを含む）
  2. 本運用規程へのリンクまたは全文
  3. FUJIN-Pサイト利用規約
  4. プライバシーポリシー

なお、ソムリエの連絡先メールアドレスのサイト上への掲示は推奨されますが、義務とはしません（第6条第3項）。

第4章　雑則

第15条（免責事項）

  1. FUJIN-P基盤の開発者および本アライアンスの運営主体は、システムの不具合、停止、データ損失等により生じた損害について、故意または重過失の場合を除き責任を負いません。
  2. 各FUJIN-Pサイトにおけるサービスの品質・可用性は、当該サイトのソムリエの責任において確保されるものとし、他のソムリエまたは運営主体はこれに関する責任を負いません。

第16条（規程の改定）

  1. 本規程は、運営主体の決定により改定することができます。
  2. 改定にあたっては、登録ソムリエに対し事前に通知するものとします。
  3. 改定に同意できないソムリエは、第10条に基づき資格を返上することができます。

第17条（準拠する運用規程）

本規程に定めのない事項、および運営主体の構成・権限・ソムリエ研修の具体的内容・資格取り消しの手続き等の詳細については、{{ORGANIZATION}}で別途定める運用規程によるものとします。
