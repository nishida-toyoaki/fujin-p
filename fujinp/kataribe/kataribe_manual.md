# 🗣 かたりべ（kataribe）ユーザーズマニュアル

かたりべは，スライドを「ページの束」ではなく，**タイル**の出入りとして組み立てるプレゼン作成・上映アプリです．タイルの中身はHTMLで自由に作れ，並べ方と現れる順番は別のモードで決めます．中身の生成は生成AIに任せ，人は流れを整えて仕上げる——そういう使い方を想定しています．

## 1. 機能概要

### 🧱 タイルとシーン
プレゼンは「シーン」の並びでできています．シーンはテーマのまとまりで，シーンが替わると画面全体が切り替わります（従来のページ替えに相当）．シーンの中には「タイル」を置きます．タイルはHTMLの断片で，見出しでもカードでも帯でも画像でも，好きな中身を入れられます．

### 🧩 行・幅・入・出
タイルには4つの数字がつきます．**行**が同じタイルは横に並びます．**幅**は行の中での比率です．**入**のステップで現れ，**出**のステップで消えます（空欄なら最後まで残る）．消えたタイルの場所は空き，残ったタイルがせり上がります．

### ↶ 元に戻す・やり直す
タイルやシーンを編集した直後なら，「↶ 元に戻す」で一手ずつ取り消せます．取り消しすぎたときは「↷ やり直す」で戻せます．キーボードのCtrl+Z（やり直しはCtrl+Shift+ZまたはCtrl+Y）でも同じです．文章を続けて打っているあいだは1手にまとめて数えるので，1文字ずつ戻ることはありません．履歴は，作品を開いた時点・新規・サンプル読み込み・取り込みのそれぞれで新しく始まります（ブラウザを閉じると消えます）．

### 📑 シーンの種別
シーンには3つの種別があります．**本文**は通常のシーンで，シーン番号と題名が表示され，タイルがステップごとに現れます．**表紙**と**エンドノート**は，番号も題名も出ず，ステップ送りもしません．タイルは開いた瞬間にすべて表示されます（文字でも画像でも自由に置けます）．種別を変えると地色の既定もそれらしく切り替わります．

### 📐 画面への自動収め
シーンの中身が画面の高さに収まらないときは，全体を少し縮めて自動的に収めます．画像の大きさやタイルの数を手で詰めなくても，上映のときに下が切れることはありません．縮小には下限（およそ45%）があり，それでも入り切らないほど長いシーンは，従来どおりスクロールになります．

### 🎨 シーンのテーマ
シーンごとに地色を選べます．**明色**（通常），**ダーク**（反転），**表紙**（紺のグラデーション・中央寄せ）の3種です．種別とは独立に変えられます．

### ⛶ 全コンテンツ表示
右上の「⛶ 全コンテンツ表示」を押すと，左の編集画面が隠れてプレゼンだけが画面いっぱいに表示されます．操作ボタンもキーボードもそのまま使えるので，この状態で上映できます．右上の「✎ 編集画面に戻る」かEscキーで元に戻ります．編集中の内容がそのまま映るので，保存前の状態でも確認できます．

## 2. 使い方

### ■ 全体の流れ
1. ダッシュボードから「かたりべ」を開きます．
2. 初めてなら「サンプル読み込み」を押すと，タイルの出入りを実演するサンプルが入ります．
3. 左側でシーンとタイルを編集し，右側のプレビューで確かめます．
4. 題名を入れて「💾 保存」．別作品として枝分かれさせるときは「📄 別名で保存」．
5. 「⛶ 全コンテンツ表示」で編集画面が隠れ，プレゼンだけが画面いっぱいになります．そのまま上映できます．

### ■ 編集の二つのモード

**🧱 タイル編集** — 上段にそのシーンのタイル一覧が出ます．行をクリックすると，そのタイル1枚だけが下に開いて編集できます（同時にすべてを開くのではなく，選んだ1枚を編集する方式です）．一覧の各行には，名前と，行・幅・入・出が小さく表示されます．

選んだタイルでは，名前，行・幅・入・出の数値，HTML本文を編集できます．一覧の下のボタンで，タイルの追加・複製・並べ替え・削除ができます．タイルを削除すると，そのシーンの「入」「出」の番号は自動的に1から順に詰め直されます（何も起きない空のステップが残ると，上映のときにそこで間延びしてしまうためです）．「入」「出」の欄の隣にある「⇅ 自動整列」を押すと，タイルが「入」の速い順に並べ替えられ，番号も1から詰め直されます．同じ番号のタイル（同時に現れるもの）は同じ番号のまま，1, 2, 2, 3 のように扱われます．「⧉ 複製」は同じ書式のタイルをもう1枚作るボタンです．列挙（①②③など）を作るときは，1枚仕上げてから複製し，中身の文字だけ差し替えてください．「📐 部品の書き方」を押すと，使えるクラスの一覧が出ます．

**🎆 HTMLを埋め込む** — 手元の自己完結HTMLファイル（アニメーションや小さなデモなど．1件8MBまで）をアップロードし，タイルのカーソル位置に `<iframe class="k-frame">` を挿入します．そのシーンに入るたびに読み込み直されるので，たどり着いた瞬間にアニメーションが最初から動きます．高さは `k-frame sm`（30vh）／`md`（45vh）／`lg`（75vh）／`full`（86vh）で変えられます．安全のため，埋め込めるのはこのサイトにアップロードしたファイルだけで，外部サイトの埋め込みは表示されません．

**🖼 画像を挿入** — 手元のPNG・JPG・SVG（1枚8MBまで）をアップロードし，編集中のタイルのカーソル位置に `<img>` を挿入します．画像はサーバの `fujinp/kataribe/img` に保存され，「🗂 アップ済み画像」からいつでも選び直せます．挿入される `<img class="k-img">` は画面に収まる大きさ（高さ52%まで）に自動調整されるので，大きな画像を入れても他のタイルが押し出されません．挿入されるタグには幅の指定（`style="width:60%;"`）が入ります．挿入前ならボタン横の「幅 ○%」で既定値を変えられ，挿入後もこの数字を書き換えれば手で調整できます．高さの方を変えたいときは `k-img sm`（小）／`md`（中）／`lg`（大）／`full`（幅いっぱい）を付け足すか，`style="width:80%; max-height:30vh;"` のように直接指定してください．インターネット上の画像を使いたいときは，`<img src="https://...">` をHTMLに直接書いてください．

**🧩 レイアウト・表示** — タイルの一覧表で，行・幅・入・出をまとめて設定します．下の「表示確認」スライダを動かすと，プレビューがそのステップの状態になります．

**🗂 シーン一覧** — 作品全体を俯瞰する表です．各シーンの種別・題名・タイル数・ステップ数が並び，題名はその場で書き換えられます．「✎」でそのシーンの編集へ移り，「▲▼」で順番を入れ替えられます．左端のチェックで選んだシーンは「⬇ 選んだシーンを書き出す」でJSONファイルになり，「📂 シーンを取り込む」で別の作品へ差し込めます．取り込みは，いま選ばれているシーンの前か後ろかを選んで挿入します．書き出したファイルのほか，作品JSON全体を渡すこともできます（その場合は全シーンが入ります）．

シーンの選択・挿入・並べ替え・削除と，シーンの題名・英字サブタイトル・種別・テーマは，左上のシーン欄でいつでも変えられます．シーンの追加は「＋前に」（いま開いているシーンの直前に挿入）と「＋後に」（直後に挿入）の2つで，挿入した新しいシーンがそのまま選ばれます．シーンを切り替えたり並べ替えたりすると，プレビューはそのシーンの最後のステップ（ふつうは全部表示された状態）を映します．前後関係を見比べながら並べ替えられます．

### ■ タイルで使える部品クラス
`k-title`（大見出し），`k-sub`（英字サブ），`k-lead`（リード文），`k-card`（カード．`violet` `rose` `green` `navy` で色違い），`k-band`（強調帯），`k-note`（脚注），`k-kicker`（タグ），`k-chip`（丸枠），`k-badge`（実績バッジ），`k-stat`（大きな数値＋ラベル），`k-num`（丸数字），`k-accent`（アクセント文字），`k-head`（カード上部の見出し帯），`k-arrow`（矢印），`k-img`（画像）．自由なHTMLと`style`属性も使えます（`script`は安全のため取り除かれます）．

### ■ 上映と練習

| ボタン | 動き |
|---|---|
| 次のステップ ▶ | タイルを1つ進める（出し切ると次のシーンへ） |
| ◀ 前のステップ | 1つ戻す（シーン先頭では前のシーンへ） |
| 次のシーンへ ▶▶ ／ ◀◀ 前のシーン | シーン単位で移動 |
| ⏮ 先頭へ | 最初のシーンに戻る |
| ▶ 自動送り | いまの位置から一定間隔で自動的に進める |
| 🎬 自動プレゼン | 先頭に戻り，最初から最後まで通しで自動再生する |
| ＋ 加速 ／ − 減速 | 自動送りの速さを1押下で1段階ずつ変更（何回でも可） |
| ×1 標準 | 速度を標準（3秒間隔）に一発で戻す |

全コンテンツ表示ではキーボードも使えます：→またはSpace＝次のステップ，←＝前のステップ，↓/PageDown＝次のシーン，↑/PageUp＝前のシーン，Home＝先頭へ，P＝自動プレゼン．加速を5回ほど重ねると，フェードが省かれて「パラパラめくり」になります．

### ■ 取り込みと書き出し
「⬇ 作品JSONを書き出す」で，プレゼンの全情報を含んだJSONファイルを保存できます．「📂 作品JSONを取り込む」では，そのファイル（または貼り付けたJSON）を読み込めます．取り込んだものは新しい作品として開くので，保存するまで元の作品は変わりません．バックアップ，別サイトへの持ち込み，生成AIに渡す素材のいずれにも使えます．

「🎞 プレゼンHTML」は，再生の仕組みごと1ファイルに固めた上映用HTMLです．かたりべにもインターネットにも接続せず，ブラウザで開くだけで動きます（アップロードした画像だけは，サイトにログインした状態で開くと表示されます）．

### ■ JSONでの直接編集
「{ } JSON」でスペック全体をテキストとして編集できます．形式は `{title, scenes:[{title, subtitle, theme, tiles:[{name, html, row, span, in, out, narration}]}]}` です．

### ■ 元の画面へ戻る
画面上部の「🏠 FUJINダッシュボードに戻る」から戻れます．保存していない変更が残っているときは確認が出て，「保存して移動」「保存せずに移動」「このまま編集を続ける」から選べます．ブラウザのタブを閉じたり別のページへ移動したりする場合も，同じように警告が出ます．

## 3. 利用上の注意

- プレゼンを作る・直せるのは現在，管理者（admin）だけです（今後グループ単位で広げる予定）．ほかの利用者も**閲覧はできます**——ダッシュボードのカードを押すとプレゼン一覧が開き，選んだものを上映画面で見られます．
- 作品は作成した本人だけが閲覧・編集できます（共有機能はありません）．
- 以前のブロック形式で作った作品も開けます．編集するときは「🔁 このシーンをタイルに変換」を押してください．
- 編集は自動保存されません．区切りのよいところで「💾 保存」を押してください（未保存のまま画面を離れようとすると確認が出ます）．取り込み（総替え）を取り消したいときは，保存せずに作品を開き直してください．
- 削除した作品は元に戻せません．
